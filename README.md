# Cpp Algorithms And Data Structures 

Kolekcja programów w języku **C++** prezentująca algorytmy, struktury danych, operacje na macierzach oraz plikach.

---

## Spis projektów

| Moduł | Główny temat / Technologie |
| :--- | :--- |
| **`Sorting-Algorithms`** | Algorytmy sortowania (MergeSort, SelectionSort), wskaźniki, rekurencja. |
| **`Przetwarzanie-Listy-Wskaznikowej`** | Odczyt danych z pliku i dynamiczne zarządzanie listą powiązaną (`ifstream`, `new`/`delete`). |
| **`Operacje-Na-Bieżącej-Liście`** | Interaktywna lista jednokierunkowa, wyszukiwanie i bezpieczne usuwanie węzłów. |
| **`Zarzadzanie-Studentami-Struktury`** | Praca ze strukturami (`struct`), losowe generowanie ocen i referencje. |
| **`Operacje-Na-Macierzach-Znakowych`** | Generowanie oraz warunkowa modyfikacja wierszy w tablicach znaków 2D. |
| **`Macierz-Struktur-Studentow`** | Siatka obiektów `struct` z algorytmami przeszukiwania. |
| **`Operacje-Na-Plikach-I-Macierzach`** | Obsługa strumieni plików (`ifstream`/`ofstream`) oraz transformacje macierzy liczbowych. |
| **`Analiza-Statystyczna-Macierzy`** | Obliczanie średnich wierszowych, modyfikacja danych i maksima kolumnowe. |
| **`Analiza-Napisow-I-Przesuniecie-Tablicy`** | Walidacja danych, operacje na klasie `string` i cykliczne przesuniętość tablic. |
| **`Analiza-Ciagu-Liczbowego-Petla`** | Pętla z warunkiem stopu, szukanie maksimum i badanie monotoniczności. |
